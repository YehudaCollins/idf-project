# שרת Mission 360

## הרצה מהירה — איזה פקודות להריץ עכשיו

פתח **שלושה טרמינלים** (או שלוש לשוניות ב־Terminal):

### טרמינל 1 — MongoDB על פורט 27018

אם עדיין לא יצרת תיקיית נתונים:

```bash
mkdir -p ~/mongo_data_2
```

הפעל את השרת (השאר את החלון פתוח):

```bash
mongod --port 27018 --dbpath ~/mongo_data_2
```

### טרמינל 2 — שרת Node

מתיקיית הפרויקט הראשית (`misson 360`):

```bash
cd server
npm install
npm run seed
npm run dev
```

- `npm run seed` — מריץ **פעם אחת** (או כשמאפסים DB) כדי ליצור משתמש מנהל ונתונים ראשוניים במסד — אחרי זה הכל דרך MongoDB בלבד.
- `npm run dev` — השרת רץ על **פורט 3001** (לא 5000 — ב־macOS פורט 5000 תפוס לעיתים על ידי AirPlay).

### טרמינל 3 — לקוח React (Vite)

```bash
cd client
npm install
npm run dev
```

פתח בדפדפן את הכתובת ש־Vite מדפיס (למשל `http://localhost:5173`). אם הפורט תפוס, Vite יבחר פורט אחר — השתמש בכתובת שמופיעה בטרמינל.

## חיבור MongoDB — שני שרתים במקביל (macOS)

השרת הרגיל של MongoDB לרוב רץ על **27017**. אפשר להריץ **שרת שני** על **27018** עם תיקיית נתונים נפרדת — כך לא מתערבים בנתונים של ה־27017.

### 1. תיקיית נתונים לשרת השני

```bash
mkdir -p ~/mongo_data_2
```

### 2. הפעלת השרת השני

```bash
mongod --port 27018 --dbpath ~/mongo_data_2
```

**חשוב:** כל עוד הפקודה רצה, השרת פעיל. סגירת החלון עוצרת את MongoDB על 27018.

### 3. MongoDB Compass

- לחץ **+** ליד CONNECTIONS.
- הזן: `mongodb://localhost:27018`
- **Connect**

כעת יש שני שרתים נפרדים: **27017** ו־**27018**.

## הגדרות האפליקציה (`server/.env`)

| משתנה | משמעות |
|--------|--------|
| `PORT` | פורט השרת (ברירת מחדל בפרויקט: **3001**) |
| `MONGO_URI` | כתובת MongoDB. בפרויקט: `mongodb://localhost:27018/mission360` — מסד הנתונים **`mission360`** נוצר אוטומטית בכתיבה הראשונה |
| `JWT_SECRET` | מפתח לחתימת JWT — בפרודקשן החלף לערך אקראי ארוך |

אחרי שינוי ב־`.env` — הפעל מחדש את `npm run dev` של השרת.
